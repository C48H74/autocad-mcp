# Support

Use [GitHub Issues](https://github.com/C48H74/autocad-mcp/issues) for bugs and feature requests. English, Português and Español are welcome. Community support has no guaranteed response time.

Check the README troubleshooting table, run `status`, and reproduce on a disposable drawing. Include repository revision, Windows/Python versions, exact AutoCAD or Plant 3D build, MCP client, sanitized arguments and error code.

Remove project names, paths and confidential content from logs. Never attach proprietary DWGs, credentials or licensed Autodesk components. Follow [SECURITY.md](SECURITY.md) for vulnerabilities.
